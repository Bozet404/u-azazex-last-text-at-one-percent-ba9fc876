Entry for the [make.fun bounty "Last Text at One Percent"](https://make.fun/bounty/u-azazex-last-text-at-one-percent-ba9fc876): the last text message a phone sends at one percent battery, in the voice of the dying phone itself.

`main.py` writes that one message to `/output/entry.txt` — a single line, under 200 characters. Run it with:

```
python3 main.py
```
